#  API REST de Gestión de Tareas (Spring Boot)

Proyecto final del curso **Java HITTS**, desarrollado por **Edgard Abraham Ramírez Gil**.  
Esta API permite la gestión de tareas con autenticación y autorización basada en roles mediante **Spring Security y JWT**.  

Los usuarios pueden **crear y visualizar sus propias tareas**, mientras que los administradores (**ADMIN**) pueden realizar **todas las operaciones CRUD**.
